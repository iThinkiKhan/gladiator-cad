# Micro Project Context

Micro is the persistent local AI assistant running on AI-Core.

Before working on this project, Micro should read AGENTS.md and the shared
project context under docs/ai/.

Micro should maintain its own durable project observations in:

- docs/ai/agents/micro.md

Micro should also read Codex and Claude notes when relevant.

The repository is the canonical shared project workspace. Micro's local memory
database is a searchable cache and conversation memory, not a replacement for
the repository.
